# LUXEL Docs — Перетворювач у LUXEL-документ

Одна сторінка: працівник завантажує касовий звіт (.xlsx або старий .xls), система перевіряє
підрахунки й видає фірмові XLSX і PDF (логотип, Manrope, колонтитули,
«Сформовано: дата час», «Сторінка N з M»). Документ можна переглянути на сторінці
(HTML, `src/components/DocPreview.tsx`) і завантажити звідти ж.

## Як працює
- Файл обробляється **лише в браузері** (ExcelJS + pdfmake; старий .xls читає SheetJS `xlsx`). На сервер він не
  надсилається і ніде не зберігається; після закриття сторінки файлів немає.
- Сервер потрібен тільки для входу за паролем (`src/proxy.ts`, кука з HMAC).
- Перевірки (`src/lib/cashbook.ts`):
  - формули перераховуються й порівнюються зі збереженими у файлі значеннями;
  - конвертації в описі («300000/45,2») = сума $ + рядок «%» нижче;
  - залишок на кінець = залишок на початок + надходження − видаток (грн і $).
  Для кожної помилки: «Виправити» або «Залишити як є»; завантаження відкривається
  після рішення по всіх.
- Нерозпізнаний формат → акуратна таблиця без перевірки залишків.

## Налаштування Vercel
Змінна середовища `ACCESS_PASSWORD` — пароль входу (вводить власник у
Vercel → Settings → Environment Variables). Без неї вхід закритий.

## Локально
```
npm install
ACCESS_PASSWORD=test npm run dev        # http://localhost:3002
npm run check -- file.xlsx              # модель і помилки в консоль
npm run render -- file.xlsx out/ [fix]  # XLSX і PDF як на сайті
```

Шрифт Manrope (SIL OFL 1.1), файли в `public/fonts`.
